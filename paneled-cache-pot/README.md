# Paneled Cache Pot

A printable cache pot project with a reusable pot core and several panel
variants.

`models/` contains the source core and panel variants. `lib/project/` contains
the shared geometry helpers used by the top-level models. Use `PROJECT.md` for
context and `REQUIREMENTS.md` for the implementation contract.

## Quick checks

- Render all migrated source files with `tests/run-render-tests.sh`
- Override the OpenSCAD binary with `OPENSCAD=/path/to/openscad` if needed
