# PROJECT.md

## Overview
This project is a migration of the older OpenSCAD experiments folder. It exists
for one-off swatches, print calibration pieces, and isolated geometry checks.

## Current shape
- `models/` contains experimental source files.
- `exports/` contains copied reference meshes from the older workspace.

## Scope guidance
- This directory is intentionally different from the product-like projects in
  `3Dmodels`: it is a sandbox, not a polished design.
- If an experiment graduates into a real part, it should move into its own
  project folder.
