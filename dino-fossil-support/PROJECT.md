# PROJECT.md

## Overview
This project is a clean-slate OpenSCAD remake of a simple dinosaur fossil
display support based only on the provided reference photos.

## Source of truth
- The local reference photos and screenshots are the source of truth for the
  silhouette.
- The goal is shape fidelity first, not reinforcement or redesign.

## Modeling approach
- Keep the part as a single 2D outline extruded to thickness.
- Keep the code simple and parameterized.
