# Emersed Plant Platforms

Migrated from the older flat `OpenSCAD` workspace into this per-project repo
structure.

`models/` contains the source `.scad` variants. `exports/` contains copied STL
and 3MF artifacts from the older workspace for reference. Use `PROJECT.md` for
context and `REQUIREMENTS.md` for the current implementation contract.

## Quick checks

- Render all migrated source files with `tests/run-render-tests.sh`
- Override the OpenSCAD binary with `OPENSCAD=/path/to/openscad` if needed
